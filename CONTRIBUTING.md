# Contributing

1. Create a branch from `main` (`feat/...`, `fix/...`, `docs/...`, `chore/...`).
2. Commit with Conventional Commits: `feat:`, `fix:`, `docs:`, `test:`, `chore:`, `ci:`.
   Explain why in the message body when it is not obvious.
3. Open a Pull Request using the template. Link the issue with `Closes #n`.
4. CI must be green before merging. No direct pushes to `main`.
